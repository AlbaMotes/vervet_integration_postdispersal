The repository includes three types of files:
- R scripts
- r formulas
- r environment

R scripts are numbered in the order they should be run inside the bayes_nets_sem folder. File paths need to be adapted to the local user.
Due to their large size, data files are stored in the Zenodo repository 10.5281/zenodo.23532870

The pipeline map summarises what each Rmd in the analysis reads, sources, defines and writes, and where a file or object changes name along the way. Scripts are listed in run order. It needs to be rendered (download it and open it in a browser).
